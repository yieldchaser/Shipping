# Fearnleys research-library table images, transcribed

Some Fearnleys report blocks are images of printed tables (the Capesize composite-model tables in the
Dry Bulk Weekly from 2026-08-26). The numbers are printed, not plotted, so they can be read exactly.
Each entry was transcribed from the image and checked against an independent OCR read (RapidOCR): the
numbers agree as multisets for all 14 images, and cell by cell (672 cells) for the 12 boxed tables from
2026-09-02 on. A highlighted row in the image is shown in bold. Totals are reproduced as printed,
including where the bucket counts do not add up (2026-08-26).

Format: a line `=== <report guid>/<image file name>` followed by the Markdown to place under that image.

Product Highlights

Mobile Vessel List

iOS Mobile App: Now access your desktop vessel lists on the go with the Signal Ocean iOS app! Easily view active tabs, saved lists, and key vessel details like ETA, DWT, and year built. Tap on any vessel for a detailed view or to update positions directly. Stay connected wherever you are.

Data Query

Platform: A seamless way to access historical data back to 2014 with refreshable downloads. Share data via secure URLs and choose formats like Time Series, Raw Data, or Pivot Mode for custom analysis. Enhance collaboration and save time with this powerful new feature.

Analytics Suite

Orderbook: Assess fleet growth and shipyard trends with the new Orderbook report, offering dynamic, actionable insights deliveries, demolitions, and orders by Vessel Class.
Waypoints: Discover global market trends with the new Waypoints report, by monitoring activity across 32 key locations, including the Suez Canal and Cape of Good Hope, using filters and comparative analytics.

P&L Extension and Free-text Notes

Voyage Calculator: With the new P&L extension, calculate daily and total P&L (profit and loss) figures, based on new inputs for Vessel Hire, Address Commission and Ballast Bonus. With the new release you can also now add notes directly within your calculations for better documentation and collaboration. Plan voyages more efficiently with these enhanced features.

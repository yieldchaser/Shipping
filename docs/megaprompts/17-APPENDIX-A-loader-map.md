# 17 — APPENDIX A: loader remediation map (measured 2026-09-12)

Every data loader in `index.html` whose mapping code reads column names that do **not** exist in the
file it loads. Generated by comparing each loader's field reads against the file's real header, with the
pre-Round-1 implementation (`git show 253691965:index.html`) shown where it existed.

**Rule: never invent a mapping. Use the real header below, or restore the pre-Round-1 logic.**


## A0 — SGX futures group (path built at runtime, so not in the table below)

`index.html` ~17393-17409 builds paths as `'data/futures/sgx_' + key + '.csv'` for
cape · panamax · supramax · handysize · fef · m65f · lpf, then keeps only rows where
`row.settlement != null`. **The files have no `settlement` column.**

Real header (`data/futures/sgx_cape_futures.csv`, ~9,175 rows, appended daily by the collector):
`contract,expiry_month,expiry_year,date,price,volume,open_interest,expiry_date`

Pre-Round-1 code read `row.settle || row.price || row.Close || row.close` (old index.html L6873)
and `row.Price || row.price || ...` (L6920). Fix: settlement → `price`, keep `volume` and
`open_interest` (both exist), drop `change`/`month_order` or derive them.
This single bug blanks the SGX FFA forward curve and the SGX iron-ore term structure on Signals.

## Summary
Main
Bulkers
Bulker S&P values were largely steady across segments this week, with only modest firming in older Panamax tonnage. Kamsarmax Aquavita Aim (82,200 DWT, 2019, Oshima) sold by Olive Shipmanagement for USD 38.2 mil, VV Value USD 37.9 mil. Kamsarmax Medi Positano (81,800 DWT, 2015, Tsuneishi Zosen) sold by D'Amico Dry Ltd for USD 31.6 mil, VV Value USD 30.6 mil.

## Main
Bulkers
Bulker S&P values were largely steady across segments this week, with only modest firming in older Panamax tonnage.
Kamsarmax Aquavita Aim (82,200 DWT, 2019, Oshima) sold by Olive Shipmanagement for USD 38.2 mil, VV Value USD 37.9 mil.
Kamsarmax Medi Positano (81,800 DWT, 2015, Tsuneishi Zosen) sold by D'Amico Dry Ltd for USD 31.6 mil, VV Value USD 30.6 mil.
Panamax Francesco Corrado (77,100 DWT, 2008, Oshima) sold by Gestion Maritime for USD 15 mil, VV Value USD 14.6 mil.
Tankers
Tanker S&P values climbed sharply for older VLCC tonnage this week, driven by ADNOC Logistics & Services' buying spree of six VLCCs over recent weeks that has pushed 20-year-old units up week-on-week.
VLCC Celeste Nova (318,500 DWT, 2013, Shanghai Waigaoqiao Shipbuilding) sold by Zodiac Maritime to ADNOC Logistics and Services for USD 120 mil, VV Value USD 112.1 mil.
VLCC Grit (298,600 DWT, 2003, Daewoo) sold by Yearn Marine for USD 50 mil, VV Value USD 51.65 mil.
Containers
Container values remain stable this week.
No notable sales this week
